This project implements Neural Style Transfer, a deep learning technique that applies the artistic style of one image to the content of another image. The result is a creative image that blends visual content with artistic patterns.
A pre-trained convolutional neural network is used to extract style and content features from the input images. Google Colab is utilized to handle the computational requirements efficiently.
Neural style transfer is widely used in digital art, creative design tools, and AI-powered media applications.
